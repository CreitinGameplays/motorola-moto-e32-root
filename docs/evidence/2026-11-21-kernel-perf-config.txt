# Kernel performance config build verification (2026-11-21/22)

VPS build of `motorola-moto-e32-kernel` `4.14` with the new performance
defaults in `build.sh` plus the `tcp_bbr.c` helper fix.  Host: 2 vCPU,
3 GB RAM, clang+lld 11.0.1, `OUT=/home/creitin/kbuild`,
`STABLE=/home/creitin/kernel-out`.

## Build

```
$ OUT=/home/creitin/kbuild STABLE=/home/creitin/kernel-out ./build.sh
...

--- stable output in /home/creitin/kernel-out (Image + modules, one build)
```

First attempt failed because the vendor drop's BBR file was never
compiled before:

```
net/ipv4/tcp_bbr.c:274:43: error: implicit declaration of function
        'bbr_min_tso_segs' [-Werror,-Wimplicit-function-declaration]
        segs = max_t(u32, bytes / tp->mss_cache, bbr_min_tso_segs(sk));
```

The 5.4.y helper was added (`bbr_min_tso_segs()`, matching the
`min_segs` already computed by `bbr_set_tso_segs_goal()`), then the
incremental rebuild finished with EXIT=0.
