## What was wrong and what closed it

1. Boot hangs (all of them): DDK power_control_init enabling aonapb-gate#9
   -> Synchronous External Abort. Fixed by the qogirl6 platform skip.
2. Magisk module autoload failure ("Unknown symbol mdbg_crumb"): the first
   staged .ko was the instrumented build, which depends on the crumb
   recorder. Fixed with the macro-gated instrumentation
   (mdbg.h, CONFIG_MALI_MDBG_CRUMB): production builds carry no MDBG code
   at all (verified: 0 references, 0 strings).
3. GPU-less boots panicked at ~148 s (hang monitor) because
   boot_completed never fired - resolved by 1+2.
